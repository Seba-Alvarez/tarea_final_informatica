# Recurso educativo desarrollado con eXeLearning

## Descripción

Este repositorio contiene la exportación de un recurso educativo desarrollado mediante **eXeLearning** como parte de una tarea académica.

El material fue diseñado con fines educativos y posteriormente exportado desde eXeLearning para su publicación y distribución a través de la web.

## Contexto académico

Este recurso forma parte de una actividad académica orientada al diseño y desarrollo de contenidos educativos digitales, aplicando herramientas de autor para la creación de materiales interactivos de aprendizaje.

## Origen del código

Los archivos incluidos en este repositorio han sido generados automáticamente por eXeLearning durante el proceso de exportación del proyecto.

Por este motivo:

* La estructura de carpetas y archivos corresponde al formato generado por la herramienta.
* Los archivos HTML, CSS y JavaScript fueron creados total o parcialmente de forma automática.
* Las modificaciones realizadas directamente sobre los archivos exportados pueden perderse si se genera una nueva exportación del proyecto original.

## Publicación

Este repositorio está destinado a ser publicado mediante **GitHub Pages**, permitiendo el acceso al recurso educativo desde un navegador web sin necesidad de software adicional.

Una vez habilitado GitHub Pages, el contenido podrá visualizarse directamente desde la URL proporcionada por GitHub.

## Visualización local

Para ejecutar el recurso localmente:

1. Clonar o descargar este repositorio.
2. Abrir el archivo `index.html` en un navegador web moderno.

## Tecnologías utilizadas

* eXeLearning
* HTML5
* CSS3
* JavaScript
